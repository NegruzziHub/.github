# Contributing

This file is the organization-wide default. Individual repositories will use their own `CONTRIBUTING.md` if they have one : this only applies where a project doesn't provide its own guidance.

## General expectations

- Branch from `main`, don't push directly to it : see [branch protection guidelines](https://github.com/NegruzziHub/CentralPoint/blob/main/docs/security/branch-protection.md) for why
- Open a pull request when your change is ready, using the [pull request template](https://github.com/NegruzziHub/CentralPoint/blob/main/templates/pull-request/PULL_REQUEST_TEMPLATE.md) as a guide
- Keep commits reasonably scoped : a pull request that does one clear thing is much easier to review than one that touches five unrelated files
- Test your change before asking someone to review it

## Reporting bugs or proposing features

Use the issue templates available in this repository under `ISSUE_TEMPLATE/` : they'll show up automatically when opening a new issue on any NegruzziHub repository that doesn't override them.

## Our standards

Coding and architecture standards live in [`CentralPoint/docs/architecture/`](https://github.com/NegruzziHub/CentralPoint/tree/main/docs/architecture). If a project-specific `CONTRIBUTING.md` doesn't say otherwise, assume those standards apply.

## Code of Conduct

All contributions are expected to follow our [Code of Conduct](https://github.com/NegruzziHub/CentralPoint/blob/main/CODE_OF_CONDUCT.md). Be patient with beginners, give feedback on the work rather than the person, and assume good intent.

## Questions

If something's unclear, ask in the club chat rather than guessing : it's faster for you and it usually means the documentation needs fixing anyway.
